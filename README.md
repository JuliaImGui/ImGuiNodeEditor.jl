# ImGuiNodeEditor.jl
[![](https://img.shields.io/badge/docs-stable-blue.svg)](https://juliaimgui.github.io/ImGuiDocs.jl/imguinodeeditor/stable)
[![](https://img.shields.io/badge/docs-dev-blue.svg)](https://juliaimgui.github.io/ImGuiDocs.jl/imguinodeeditor/dev)

This package provides Julia bindings for
[imgui-node-editor](https://github.com/thedmd/imgui-node-editor), a node editor
library for [Dear ImGui](https://github.com/ocornut/imgui) (available in Julia
from [CImGui.jl](https://juliaimgui.github.io/ImGuiDocs.jl/cimgui)). See the
docs for more information.
