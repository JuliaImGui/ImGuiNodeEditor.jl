API Reference

This page documents the wrapper functions we have for the imgui-node-editor API.

ImGuiNodeEditor.@with_font_scale — Macro
@with_font_scale scale body

Run body with a font pushed so text drawn inside the node canvas renders at scale× the base font size as measured on screen, regardless of zoom. The canvas magnifies the draw list by current_scale, so the local font is sized to scale / current_scale() and the glyphs are baked at their on-screen size (rasterizer density = the magnification, snapped to a power of two) — this keeps them crisp rather than minifying a too-large atlas (which aliases). Font and rasterizer density are restored afterwards; body's value is forwarded.

For example, a node title that stays readable (capped at 1× on screen) when zooming out but grows freely when zooming in:

@with_font_scale max(1f0, current_scale()) draw_title()

ImGuiNodeEditor.current_scale — Method
current_scale() -> Float32

Factor by which the canvas magnifies drawn content on screen: > 1 when zoomed in, < 1 when zoomed out. This is the reciprocal of GetCurrentZoom, which returns the canvas InvScale (and so reads backwards). Returns 1 when no editor is active, or when the zoom is non-positive (which a corrupt settings file or a bad CustomZoomLevels can produce).
